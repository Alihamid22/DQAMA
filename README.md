# Portfolio van Quinten

## Starten met XAMPP

1. Zet Apache aan in het XAMPP Control Panel.
2. Open in de browser: `http://localhost/demo/DQAMA/porfolio-Quinten/`

De startpagina verwijst automatisch door naar `php/portfolio.php`. De pagina's gebruiken alleen lokale CSS-, JavaScript- en afbeeldingsbestanden; een database of extra installatie is niet nodig.
